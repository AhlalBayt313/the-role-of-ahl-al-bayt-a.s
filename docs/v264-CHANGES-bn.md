# v264 — হোম পেজ: মোবাইলের ডিজাইন ডেস্কটপ ও ট্যাবলেটেও একই

v263-এর ওপর। শুধু CSS (`assets/css/style.css`-এর শেষে নতুন v264 ব্লক) এবং `sw.js` → `ahlbayt-v264`। কোনো JS, ধর্মীয় লেখা বা ডেটা বদলায়নি।

## এখন সব স্ক্রিনে একই
- দ্রুত অ্যাক্সেস সারি (দোয়া · তাসবিহ · কিবলা · ক্যালেন্ডার · ইমামগণ)
- নামাজ ব্যানারে ৫ ওয়াক্তের সারি ও অগ্রগতি বার
- ছোট (কম্প্যাক্ট) হিরো — পরিসংখ্যান সারি, অর্ধচন্দ্র ব্যাজ, আরবি সাব-টাইটেল ও ডট-বিভাজক লুকানো
- একই ক্রম: এক কলাম, আজকের হাদিস আগে (ডেস্কটপের ডান সাইডবার আর নেই)
- কম্প্যাক্ট ফিচার কার্ড ("দেখুন" পিল ও hover-ব্যাজ লুকানো)

## ফেরত নেওয়া
CSS-এর শেষের v264 ব্লকটি মুছে দিলে ডেস্কটপ আগের লেআউটে ফিরবে।
