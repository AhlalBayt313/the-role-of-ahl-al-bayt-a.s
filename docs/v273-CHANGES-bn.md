# v273 — ডার্ক মোডে "Skyline Depth" দেখা যাওয়া

v272-এর ওপর। কোনো ধর্মীয় লেখা বা ডেটা ফাইল বদলায়নি। **লাইট মোড অপরিবর্তিত।**

## সমস্যা (দুটি কারণ)
1. v272 ডার্ক মোডে `#pk-sky` ইচ্ছাকৃতভাবে `display: none` করেছিল (শুধু লাইট মোডের জন্য বানানো)।
2. শুধু লুকানো সরালেও লাভ হতো না — সিলুয়েটের রঙ (নীল/ইন্ডিগো, opacity ০.২৪–০.৩৬) হালকা ব্যাকগ্রাউন্ডের জন্য; ডার্কের `#061410`-এ প্রায় অদৃশ্য।

## সমাধান
`assets/css/style.css`-এর শেষে নতুন **v273 ব্লক** (শুধু `html[data-theme="dark"]`-এ স্কোপড):
| স্তর | লাইট (অপরিবর্তিত) | ডার্ক (নতুন) |
|---|---|---|
| দূর `.pk-l1` | নীল `#4E9CE8` | অ্যাকোয়া `#70D6C5`, opacity ০.২২ |
| মাঝ `.pk-l2` | ইন্ডিগো `#4D52B4` | নীল `#4E9CE8`, opacity ০.২৬ |
| কাছে `.pk-l3` | গাঢ় ইন্ডিগো `#292C66` | সোনালি `#E6C36A`, opacity ০.৩০ |

- দিগন্ত-আভা: সোনালি + অ্যাকোয়া (ডার্ক-উপযোগী, হালকা)।
- রিডার মোড (`body.rm-on`) ও প্রিন্টে ডার্কেও লুকানো।
- `index.html`, `skyline-parallax.js`, SVG মার্কআপ — **অপরিবর্তিত**; প্যারালাক্স ডার্কেও আপনাআপনি চলে।
- `sw.js` → `ahlbayt-v273`।

## যাচাই
- `node --check sw.js`, `tools/check-all.js` (১০টি চেক), `tools/phase4a-smoke-test.js` পাস।
- Playwright (৩৯০px): ডার্কে `#pk-sky` display `block`, রিডার মোডে `none`; স্ক্রলে স্তরের সরণ −১০/−২২/−৪০px; কোনো JS এরর নেই।
- লাইট মোডের নিয়ম-স্কোপ অপরিবর্তিত (নতুন সব নিয়ম ডার্ক-স্কোপড)।

## জানা দরকার
- হোমের কার্ড ও নিচের ডক সিলুয়েটের বড় অংশ ঢেকে রাখে; ফাঁকা জায়গায় ও পেজের নিচের দিকে বেশি দেখা যায়।
- স্পষ্টতা (বেশি উজ্জ্বল/ম্লান) আসল ফোনে দেখে বললে opacity টিউন করা যাবে (ডার্ক ব্লকের তিনটি `fill-opacity`)।
