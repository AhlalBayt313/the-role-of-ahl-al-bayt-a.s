# v265 — হোম পেজ ফিনিশ (আরও সুন্দর)

v264-এর ওপর। CSS-এর শেষে নতুন v265 ব্লক, `script-2-ui.js`-এ ছোট দুটি সন্নিবেশ, `sw.js` → `ahlbayt-v265`। কোনো ধর্মীয় লেখা বা ডেটা ফাইল বদলায়নি।

- **ডেস্কটপে প্রস্থ:** হোমের কনটেন্ট এখন প্রায় ১০৮০px-এ মাঝখানে (≥১০২৪px); পাঁচ আইকন আর দূরে ছড়ায় না।
- **হিজরি কার্ড:** পূর্ণ প্রস্থ — বাঁয়ে তারিখ, ডানে "পরবর্তী ঘটনা" (≥৭৬৮px)।
- **বিভাজক:** মূল কনটেন্টের ওপরে সোনালি রেখা ও মাঝে আটকোণা হিরা।
- **নামাজ ব্যানার:** সোনালি কিনারা ও নরম ছায়া, হিরোর সঙ্গে একই পরিবার।
- **"আনুমানিক" নোট:** ছোট পিল ব্যাজে।
- **পরবর্তী ওয়াক্ত:** ধীর সোনালি glow (`prefers-reduced-motion`-এ বন্ধ)।
- **দ্রুত অ্যাক্সেস:** জ্ঞান কেন্দ্র · রমজান · কুইজ যোগ (মোট ৮টি; ছোট স্ক্রিনে সরানো যায়)।
