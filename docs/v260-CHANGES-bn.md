# v260 — সাপ্তাহিক দোয়া ক্যাটাগরি গোছানো

**সমস্যা:** "সাপ্তাহিক" চিপে (`special-days`) ১৩টি দোয়া ছিল, যার ৪টি সাপ্তাহিক নয়।

## এখন সাপ্তাহিক চিপে (৯টি)
| # | দোয়া |
|---|-------|
| ১–৭ | শনি থেকে শুক্রবারের দোয়া |
| ৮ | জুমার দিনের আহ্বান (সূরা জুমুআ ৬২:৯) |
| ৯ | দোয়া সিমাত (জুমাবার সূর্যাস্তের আগে) |

## সরানো হয়েছে (৪টি)
| দোয়া | নতুন ক্যাটাগরি | কারণ |
|-------|----------------|------|
| ঈদের তাকবির | রমজান (+ হজ্জ-উমরাহ-তেও দেখা যায়) | বছরে ২ বার, সাপ্তাহিক নয় |
| লাইলাতুল কদরের মর্যাদার আয়াত | রমজান | বার্ষিক রমজানের রাত |
| গোপন বিষয় প্রকাশের দিনের কথা স্মরণ (৮৬:৯) | কুরআনিক | কুরআনের আয়াত, নির্দিষ্ট সাপ্তাহিক দিন নেই |
| দোয়ায়ে গাদীর | আহলুল বাইত | ঈদে গাদীরের বার্ষিক দোয়া |
